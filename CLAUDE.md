`npm run build -w @dirtyworks/web`. Run them separately so one failure cannot hide another.

## Browser smoke tests

Scratch scripts in `.superpowers/e2e/` (gitignored) drive the installed Microsoft Edge through
`playwright-core` with SwiftShader. With `npm run dev` running:

```bash
cd .superpowers/e2e && npm install && node rc-smoke.mjs shots
```

Functional smokes pre-seed tilt-shift off (`no-tilt.mjs`): SwiftShader is a CPU rasterizer and the
composer makes it ~4× slower. The dev-only handle `window.__dirtyworks = { runtime, spawn }` exposes
game state to the scripts.
